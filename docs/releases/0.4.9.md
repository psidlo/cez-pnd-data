# CEZ PND 0.4.9

Historical release preparation, retained for traceability. No GitHub Release
or tag was created; publication is not planned. Current usage and configuration
are documented in [README](../../README.md), [the archive guide](../archive.md)
and [the upgrade guide](../pnd-consolidated-migration.md).

## Changes

This release consolidates the MQTT availability repair, DIP/HDO authorization
and date/time fixes, optional SQLite archive and bounded historical backfill
from [PR #2](https://github.com/psidlo/cez-pnd-data/pull/2).

- MQTT runs its network loop, waits for connection acknowledgement, restores
  retained discovery/availability on reconnect and flushes outgoing messages
  before shutdown.
- HDO initializes backend authorization through the DIP dashboard, safely
  bootstraps its token and distinguishes authorization rejection from maintenance.
  Dated schedules use Europe/Prague; next-switch values include a UTC offset.
- Existing MQTT domains, topics and identities are preserved. Last-known display
  values survive null rows; the raw archive is never filled with those values.
- Archive is opt-in, uses explicit calendar days and midnight endpoints, retains
  raw rows and quality, and refuses unknown migrations or conflicting metadata.
  Published and archived meters can be selected independently.
- SIGTERM cancels active polling, wakes an idle asyncio selector and cleans up
  MQTT, the browser and archive resources.
- Diagnostics suppress credentials, identifying configuration and private
  responses. The existing CI has been consolidated and repaired.

## Upgrade

1. Read [migration and rollback](../pnd-consolidated-migration.md).
2. Preserve a consistent database backup including WAL data, the original
   sources, options and app identity.
3. The public manifest uses `cez-pnd`. Existing local `cez-pnd-external`
   installations must preserve their own slug, broker options and private
   settings through the local overlay; do not install a parallel publisher.
4. Verify normal PND, MQTT availability, HDO and database compatibility first.
   Archive is disabled by default; enable it explicitly with a small global
   request budget, initially one day per cycle.

The add-on and Python project versions are aligned at 0.4.9. Intermediate
0.4.2–0.4.8 labels were local revisions; this release does not invent separate
public changelogs for them. The GitHub source archive uses the public manifest
and is not a byte-for-byte backup of a private local installation.

## Known limits

- Request-rejection cooldown is process-local and resets on restart.
- MQTT LWT covers the first published meter; multi-meter atomic offline status
  is not provided.
- Backfill is serial; large budgets delay normal polling.
- Missing daily registers and incomplete profiles remain unknown/missing.
- Last-known MQTT display values do not establish freshness of each metric.
- Legacy Rv retains its source kW/value without an unverified unit conversion.
- Security checks retain advisory status and are not a guarantee that
  dependencies or images have no vulnerabilities.
